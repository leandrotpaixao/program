# 🎲 Monte Carlo PRO — Instalador Automático

## ⚡ Instalação Rápida (2 Minutos)

Escolha o seu sistema operacional:

### 🪟 **Windows**

#### Opção 1: Um-clique (Recomendado)
1. Baixe este arquivo: [install.bat](https://github.com/leandrotpaixao/program/raw/main/install.bat)
2. Clique 2x no arquivo `install.bat`
3. Aguarde a instalação (pode abrir várias janelas)
4. A aplicação iniciará automaticamente!

#### Opção 2: Prompt de Comando
```cmd
curl -L -o install.bat https://raw.githubusercontent.com/leandrotpaixao/program/main/install.bat
install.bat
```

#### Opção 3: PowerShell
```powershell
IEX (New-Object Net.WebClient).DownloadString('https://raw.githubusercontent.com/leandrotpaixao/program/main/install.bat')
```

---

### 🐧 **Linux / Mac**

#### Opção 1: Um comando no terminal
```bash
bash <(curl -L https://raw.githubusercontent.com/leandrotpaixao/program/main/install.sh)
```

#### Opção 2: Baixe o script
```bash
wget https://raw.githubusercontent.com/leandrotpaixao/program/main/install.sh
chmod +x install.sh
./install.sh
```

## ❓ Perguntas Frequentes

### "Python não encontrado"
**Solução:**
- Windows: Baixe em https://www.python.org/downloads/
  - Marque: ✓ Add Python to PATH
- Mac: `brew install python3`
- Ubuntu/Debian: `sudo apt-get install python3`

### "Permissão negada (Linux/Mac)"
```bash
chmod +x install.sh
./install.sh
```

### "Conexão recusada"
- Verifique sua internet
- Tente usar VPN se estiver bloqueado

### "Arquivo corrompido"
- Delete `install.bat` ou `install.sh`
- Baixe novamente
